# `colorhex.rs` 源码解读

**核心职责:** 提供将十六进制颜色字符串解析为 u32 颜色的工具函数，支持 1、2、3、4、6、8 位十六进制格式。

## 函数 `hex_bytes_to_u32`

**路径:** 第21-92行

将字节切片形式的十六进制颜色值解析为 u32 颜色（ARGB 格式）。不支持前导 `#`——调用者需自行去掉。

### 内部函数 `hex_to_int`（第22-33行）
将单个十六进制字符字节转换为数值：
- `0-9` → `0-9`
- `A-F` / `a-f` → `10-15`
- 其他字符 → `Err(())`

### 按长度分派（第35-91行）

| 字节数 | 格式 | 编码逻辑 |
|--------|------|----------|
| 1 | `#w` | 灰度，4 位扩展为 32 位灰度 + 0xFF alpha |
| 2 | `#ww` | 8 位灰度，扩展到 RGB 通道 |
| 3 | `#rgb` | 每位 4 位，扩展到 8 位通道（`r<<28 | r<<24 | g<<20... | 0xff`） |
| 4 | `#rgba` | 每位 4 位，包含 alpha |
| 6 | `#rrggbb` | 标准 RGB，alpha=0xff |
| 8 | `#rrggbbaa` | 标准 RGBA |

解析结果以 `0xRRGGBBAA` 格式返回（非 0xAARRGGBB 格式），原因是代码中将 R 位移到 bit 24-31，G 到 bit 16-23，B 到 bit 8-15，A 到 bit 0-7。这在调用端需对应转换。
