# `yuv.rs` — YUV 平面数据与格式定义

## 概述
该文件定义了软件视频解码路径中 YUV 数据的核心类型，包括颜色矩阵枚举、平面布局枚举、以及存储解码帧的 `YuvPlaneData` 结构体。

---

## `YuvColorMatrix`
颜色矩阵标准枚举，`#[repr(u8)]` 布局便于直接传递给着色器 uniform：
- **`BT709 = 0`**：高清电视标准（HD）。
- **`BT601 = 1`**：标清电视标准（SD）。
- **`BT2020 = 2`**：超高清电视标准（UHD）。

`as_f32()` 将枚举值直接转换为 `f32`，适合传入 GPU shader。

---

## `YuvLayout`
YUV 采样布局枚举：
- **`I420`**：Y 全分辨率，U/V 水平垂直各半采样（4:2:0）。
- **`I422`**：Y 全分辨率，U/V 水平半采样垂直全分辨率（4:2:2）。
- **`I444`**：Y/U/V 全分辨率（4:4:4）。
- **`I400`**：仅 Y 平面，灰度（4:0:0）。

**`chroma_size(luma_w, luma_h)`**：根据亮度的宽高计算色度平面的宽高：
- I420：`(w/2 向上取整, h/2 向上取整)`
- I422：`(w/2 向上取整, h)`
- I444：`(w, h)`
- I400：`(0, 0)`（无色度平面）

---

## `YuvPlaneData`
解码后的 YUV 帧数据结构，包含三个独立的平面向量：
- **`y: Vec<u8>`**：亮度平面数据。
- **`u: Vec<u8>`**：蓝色差平面数据。
- **`v: Vec<u8>`**：红色差平面数据。
- **`width: u32` / `height: u32`**：帧分辨率（亮度分辨率）。
- **`layout: YuvLayout`**：采样布局，决定色度平面的实际尺寸。
- **`matrix: YuvColorMatrix`**：颜色矩阵标准，用于后续渲染时的颜色空间转换。

该结构体实现了 `Clone` 和 `Debug`，并作为 `take_yuv_frame()` 的返回值在 `PlaybackSessionHandle` 和 `MseDecodedFrame` 之间传递。
