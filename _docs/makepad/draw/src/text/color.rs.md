# `color.rs` — 文本颜色类型

## 文件定位

该文件定义了 Makepad 文本渲染子系统的 `Color` 类型，用于表示**RGBA 颜色**。它提供了 16 种预定义颜色常量，对应于终端模拟器中经典的 ANSI 16 色方案，适用于文字渲染和终端仿真场景。

## `Color` 结构

```rust
pub struct Color {
    pub r: u8,  // 红色通道 (0-255)
    pub g: u8,  // 绿色通道 (0-255)
    pub b: u8,  // 蓝色通道 (0-255)
    pub a: u8,  // Alpha 通道 (0-255)
}
```

### 构造方法
- `const fn new(r, g, b, a)` — 编译期常量构造器

## 预定义颜色常量

### 标准 8 色（亮度约 50%）
| 常量名 | R | G | B | 等效 ANSI 码 |
|--------|---|---|---|-------------|
| `BLACK` | 0 | 0 | 0 | 0 |
| `RED` | 128 | 0 | 0 | 1 |
| `GREEN` | 0 | 128 | 0 | 2 |
| `YELLOW` | 128 | 128 | 0 | 3 |
| `BLUE` | 0 | 0 | 128 | 4 |
| `MAGENTA` | 128 | 0 | 128 | 5 |
| `CYAN` | 0 | 128 | 128 | 6 |
| `WHITE` | 192 | 192 | 192 | 7 |

### 高亮 8 色（亮度约 100%）
| 常量名 | R | G | B | 等效 ANSI 码 |
|--------|---|---|---|-------------|
| `BRIGHT_BLACK` | 128 | 128 | 128 | 8 (亮黑/灰) |
| `BRIGHT_RED` | 255 | 0 | 0 | 9 |
| `BRIGHT_GREEN` | 0 | 255 | 0 | 10 |
| `BRIGHT_YELLOW` | 255 | 255 | 0 | 11 |
| `BRIGHT_BLUE` | 0 | 0 | 255 | 12 |
| `BRIGHT_MAGENTA` | 255 | 0 | 255 | 13 |
| `BRIGHT_CYAN` | 0 | 255 | 255 | 14 |
| `BRIGHT_WHITE` | 255 | 255 | 255 | 15 |

### 亮度差异说明

标准色（ANSI 0-7）使用 128 作为主色值（对于非黑色），白色使用 192，这对应于老式终端中"半亮"的显示效果。亮色变体（ANSI 8-15）使用 255 作为主色值，产生完全的亮色显示。

`BRIGHT_BLACK` 的 R=G=B=128 实际上是一种灰色，对应于 ANSI 中的"亮黑"或"深灰"效果。

## 设计特点

1. **`const fn` 构造器** — 所有常量都可以在编译期求值，零运行时开销
2. **RGBA 顺序** — 使用标准 RGBA 通道顺序（不同于 `image.rs` 中的 `Bgra` 像素格式），表明这是逻辑颜色表示而非物理像素格式
3. **`Copy` + `Clone`** — 轻量值类型，仅 4 字节
4. **`Eq` + `Hash`** — 支持颜色相等性比较和哈希，可用于缓存和比较

## 与 `image.rs` 中 `Bgra` 格式的关系

`Color` 是**逻辑颜色**（关心 R/G/B/A 通道的语义含义），而 `Bgra` 是**物理像素格式**（内存中的字节排列为 BGRA）。两者之间的转换通常发生在将文本颜色写入帧缓冲时：
- `Color { r, g, b, a }` → `Bgra::new(b, g, r, a)`

## 可能的应用场景

- 终端仿真器中的 ANSI 转义序列颜色解析
- 语法高亮的主题颜色定义
- 文本渲染中的前景色/背景色设置
