# File: d3d11.rs

- **核心用途**: 封装 Direct3D 11 核心渲染管线的完整状态管理，包括设备创建、纹理管理、Shader 资源绑定、Blend/Rasterizer/DepthStencil 状态管理以及管线状态缓存，为 Makepad 在 Windows 上的 GPU 渲染提供底层抽象。
- **所属层级**: 平台层 · Direct3D 11 图形抽象
- **涉及行数**: ~5800 行（该平台最大的单个文件之一）

---

| 名称 | 可见性 | 简介 |
|------|--------|------|
| `ShaderType` | `pub` | Shader 阶段枚举：`Vertex`, `Pixel`, `Compute`, `Geometry`, `Hull`, `Domain`。 |
| `PrimitiveType` | `pub` | 图元拓扑枚举：`PointList`, `LineList`, `TriangleList`, `TriangleStrip`, `LineStrip`。 |
| `DepthFunc` | `pub` | 深度测试函数枚举（`Always`, `Never`, `Equal`, `Less` 等 8 种标准模式）。 |
| `BlendOp` | `pub` | 混合操作枚举（`Add`, `Subtract`, `RevSubtract`, `Min`, `Max`）。 |
| `BlendFactor` | `pub` | 混合因子枚举（`Zero`, `One`, `SrcColor`, `InvSrcColor`, `SrcAlpha`, `InvSrcAlpha`, `DstColor` 等）。 |
| `Shader` | `pub` | 单个 Shader 对象，包含 `native: Option<NativeShader>` 和 `reflect: ShaderReflect`。 |
| `ShaderReflect` | `pub` | Shader 反射信息，包含 `buffers: Vec<BindBuffer>`、`tex: Vec<BindTexture>` 绑定描述。 |
| `BindBuffer` | `pub` | 常量缓冲区的绑定描述：`slot`, `name`, `size`, `stages`。 |

## 核心结构体

| 名称 | 可见性 | 简介 |
|------|--------|------|
| `D3D11` | `pub` | D3D11 渲染状态总容器，持有 `Device`, `DeviceContext`, `FeatureLevel`，以及 OMS/Rasterizer/VS/PS/RS/GS/DS/HS 各阶段的状态缓存对象池。 |
| `D3D11Pipeline` | `pub` | 管线状态快照，用于 `snapshot`/`restore` 模式，保存所有管线阶段的状态。 |
| `D3D11State` | `pub` | 单个可渲染对象的时变状态，包含 VertexBuffer 绑定、IndexBuffer 绑定、Shader 资源绑定、常量缓冲绑定。 |
| `D3D11Resources` | `pub` | 纹理、渲染目标、深度模板、UAV 等 GPU 资源的集合与生命周期管理。 |

## 实现细节

- 所有 D3D11 状态对象（Blend/Rasterizer/DepthStencil/Sampler）通过哈希键（`StateKey`）缓存重用，避免重复创建 COM 对象。
- `D3D11Pipeline` 包含完整管线状态：IA、VS、HS、DS、GS、PS、CS 的 Shader 及对应 ClassInstance、OM Blend/DepthStencil、Rasterizer。
- `D3D11State` 缓存当前绑定的 VB/IB/SRV/UAV/CBV，`apply_state` 使用增量更新减少 API 调用。
- Shader 反射使用 `ID3D11ShaderReflection` 接口解析常量缓冲区变量名与绑定槽位。

## 性能优化

- 状态对象哈希缓存消除重复创建开销。
- 增量状态应用减少 D3D11 API 调用频率。
- `update_buffer_on_draw` 配合 `Map+Unmap` 实现动态缓冲区更新。
- 支持 `DeferredContext` 命令列表记录用于多线程渲染。

## 平台集成

- 纯 Windows 平台，通过 `windows-sys` FFI 调用 D3D11 API。
- 需要 `d3d11.dll` 和 `d3dcompiler_47.dll`（编译器反射）。
- 调试支持需安装 Windows SDK D3D11 Debug Layer。
- `FeatureLevel` 至少需要 10.0，按 11.1 → 11.0 → 10.1 → 10.0 降级尝试。
