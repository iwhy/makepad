# `opcode.rs` — 字节码指令集定义

## 概述

本文件是 Makepad Splash 脚本虚拟机（VM）的**字节码操作码定义**模块。它定义了两个核心类型：

- `Opcode`（操作码枚举包装）：为每个 VM 指令分配一个 `u8` 编号，并提供完整的 Display/Debug 实现
- `OpcodeArgs`（操作码参数包装）：将附着在操作码后的 `u32` 参数编码为类型标记 + 数值的组合

---

## `OpcodeArgs` — 操作码参数编码

`OpcodeArgs` 包装一个 `u32`，通过高位比特标记参数类型：

| 掩码 | 含义 |
|------|------|
| `TYPE_NONE` = `0` | 无参数 |
| `TYPE_NIL` = `1 << 28` | 参数为 nil（无值） |
| `TYPE_NUMBER` = `2 << 28` | 参数为整数（有效位 `0–27`） |
| `NEED_NIL_FLAG` = `1 << 31` | 需要压入 nil |
| `POP_TO_ME_FLAG` = `1 << 30` | 执行后需调用 `pop_to_me` |
| `MAX_U32` = `(1 << 28) - 1` | 参数数值最大值 |

### 方法列表

| 方法 | 说明 |
|------|------|
| `raw()` | 返回裸 `u32` 值 |
| `from_u32(jump_to_next)` | 从 `u32` 构造，设定类型为 `TYPE_NUMBER`，低 28 位为跳转偏移 |
| `set_need_nil()` | 设置 `NEED_NIL_FLAG` 标记位并返回新值 |
| `to_u32()` | 提取低 29 位的纯数值（屏蔽类型标记） |
| `arg_type()` | 返回高位类型标记（与 `TYPE_MASK` 做与运算） |
| `is_need_nil()` | 判断是否设置了 `NEED_NIL_FLAG` |
| `is_pop_to_me()` | 判断是否设置了 `POP_TO_ME_FLAG` |
| `is_nil()` | 判断类型标记是否为 `TYPE_NIL` |
| `is_u32()` | 判断类型标记是否为 `TYPE_NUMBER` |

### 实现逻辑

- `from_u32`：将跳转偏移与 `TYPE_NUMBER` 做或运算组合，保留低 28 位有效性。
- `Display` / `Debug`：根据 `arg_type()` 输出格式：
  - `TYPE_NONE` → 空字符串
  - `TYPE_NIL` → `(nil)`
  - `TYPE_NUMBER` → `(N)` 其中 N 为数值
- 若 `is_pop_to_me()` 为 true，则追加 `<m>` 标记。

## `Opcode` — 操作码编号

`Opcode` 是包装 `u8` 的强类型，定义了 Splash VM 的全部 131 个操作码。

### 方法列表

| 方法 | 说明 |
|------|------|
| `raw()` | 返回裸 `u8` 值 |
| `is_assign()` | `const fn`，判断操作码是否在 `ASSIGN_ME`(25) 到 `ASSIGN_INDEX_IFNIL`(65) 的赋值操作码区段内 |

### 操作码分类

#### 运算操作码 (0–24)

| 编号 | 常量 | 运算符 | 描述 |
|------|------|--------|------|
| 0 | `NOP` | `nop` | 空操作 |
| 1 | `NOT` | `!` | 逻辑非 |
| 2 | `NEG` | `neg` | 数值取负 |
| 3 | `MUL` | `*` | 乘法 |
| 4 | `DIV` | `/` | 除法 |
| 5 | `MOD` | `%` | 取模 |
| 6 | `ADD` | `+` | 加法（支持字符串拼接） |
| 7 | `SUB` | `-` | 减法 |
| 8 | `SHL` | `<<` | 左移位 |
| 9 | `SHR` | `>>` | 右移位 |
| 10 | `AND` | `&` | 按位与 |
| 11 | `OR` | `\|` | 按位或 |
| 12 | `XOR` | `^` | 按位异或 |
| 13 | `CONCAT` | `..` (字符串连接) | 字符串拼接 |
| 14 | `EQ` | `==` | 深度相等比较 |
| 15 | `NEQ` | `!=` | 深度不等比较 |
| 16 | `LT` | `<` | 小于 |
| 17 | `GT` | `>` | 大于 |
| 18 | `LEQ` | `<=` | 小于等于 |
| 19 | `GEQ` | `>=` | 大于等于 |
| 20 | `LOGIC_AND_TEST` | `&&?` | 逻辑与短路测试 |
| 21 | `LOGIC_OR_TEST` | `\|\|?` | 逻辑或短路测试 |
| 22 | `NIL_OR_TEST` | `\|??` | nil 合并短路测试 |
| 23 | `SHALLOW_EQ` | `===` | 浅相等比较 |
| 24 | `SHALLOW_NEQ` | `!==` | 浅不等比较 |

#### 赋值操作码 (25–65)

**`this` 赋值（25–29）：**

| 编号 | 常量 | 描述 |
|------|------|------|
| 25 | `ASSIGN_ME` | `:` — 命名属性赋值（对象/函数参数） |
| 26 | `ASSIGN_ME_BEFORE` | `:<` — 插入到命名属性之前 |
| 27 | `ASSIGN_ME_AFTER` | `:>` — 插入到命名属性之后 |
| 28 | `ASSIGN_ME_BEGIN` | `:<<` — 插入到对象 vec 起始 |
| 29 | `ASSIGN_ME_VEC` | `:=` — vec 命名赋值 |

**作用域赋值（30–41）：**

| 编号 | 常量 | 描述 |
|------|------|------|
| 30 | `ASSIGN` | 普通赋值 `=` |
| 31–40 | `ASSIGN_ADD` ~ `ASSIGN_SHR` | 复合赋值 `+=` `-=` `*=` `/=` `%=` `&=` `\|=` `^=` `<<=` `>>=` |
| 41 | `ASSIGN_IFNIL` | 仅在值为 nil 时赋值 `?=` |

**字段赋值（42–53）：** `obj.field = val` 及其复合变体（`ASSIGN_FIELD` `ASSIGN_FIELD_ADD` `ASSIGN_FIELD_SUB` `ASSIGN_FIELD_MUL` `ASSIGN_FIELD_DIV` 等）

**索引赋值（54–65）：** `obj[idx] = val` 及其复合变体（`ASSIGN_INDEX` `ASSIGN_INDEX_ADD` `ASSIGN_INDEX_SUB` 等）

#### 对象/数组构造 (66–72)

| 编号 | 常量 | 描述 |

### `Display` / `Debug` 实现逻辑

`Display for Opcode` 对每个操作码输出其助记符字符串（如 `+` `-` `.=` `[]` `if` `for1` 等）。对未定义的操作码输出 `OP{n}` 格式。此实现用于字节码反汇编和调试输出。
